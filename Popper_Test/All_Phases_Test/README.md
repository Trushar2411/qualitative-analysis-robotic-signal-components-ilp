# All Phases Popper Test

This experiment trains one Popper target at a time for each detected task phase.
The shared qualitative background knowledge is reused across phase targets.

## Detected Phases

- `home`
- `gripper_opening`
- `pick`
- `pick_delay`
- `gripper_closing`
- `lift`
- `place`
- `retract`
- `return_home`

## Files

- `full_motion_joint_states.csv`: source data
- `bk.pl`: shared qualitative background knowledge for all targets
- `set_target.py`: rewrites `bias.pl` and `exs.pl` for one selected phase
- `bias.pl` / `exs.pl`: initialized for `home`
- `generate_all_phases.py`: regenerates the per-phase Popper datasets
- `run_all_phases_10_times.sh`: runs all 9 targets 10 times each
- `all_phases_hypothesis_summary.txt`: generated by the run script
- `All_Phases_Test/`: generated per-phase target folders

## Deadbands

- Position: `0.002` rad
- Velocity: `0.01` rad/s
- Effort: `0.05` in `/joint_states` effort units

## Run All Targets

```bash
cd ~/qualitative-analysis-robotic-signal-components-ilp/Popper
../Popper_Test/All_Phases_Test/run_all_phases_10_times.sh "$PWD"
```

## Set One Target

```bash
python3 ../Popper_Test/All_Phases_Test/set_target.py lift
uv run popper.py ../Popper_Test/All_Phases_Test --noisy -v
```

## Regenerate Phase Folders

```bash
python3 ../Popper_Test/All_Phases_Test/generate_all_phases.py
```
