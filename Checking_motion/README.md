# Checking Motion

This folder contains a small qualitative motion checker for a robotic pick-and-place trajectory.

## Files

- `check_pick_and_place.py` reads a joint-state CSV and checks whether the motion matches a learned pick-and-place sequence.
- `full_motion_joint_states_modified.csv` contains the recorded joint-state data used by the checker.

## What the Code Does

The Python script loads `full_motion_joint_states_modified.csv` with pandas. The CSV contains timestamp columns plus position, velocity, and effort values for joints 1 through 6.

For every pair of consecutive rows, the script compares each joint signal against a threshold and converts the numeric change into a qualitative fact:

- `increases` if the value rises above the threshold
- `decreases` if the value falls below the negative threshold
- `constant` if the change stays within the threshold

The thresholds used are:

| Signal type | Threshold |
| --- | ---: |
| Position | `0.002` |
| Velocity | `0.01` |
| Effort | `0.05` |

For example, if joint 2 position increases enough between two rows, the script records the qualitative fact `j2_pos_increases`. If joint 3 position decreases enough, it records `j3_pos_decreases`.

After building these qualitative facts, the script checks for learned phase rules that represent a pick-and-place motion:

| Phase | Learned rule |
| --- | --- |
| Pick | `j3_pos_decreases AND j2_pos_increases` |
| Lift | `j1_pos_decreases` |
| Place | `j2_pos_increases AND j3_pos_increases` |
| Retract | `j3_pos_constant AND j2_pos_decreases` |
| Return home | `j5_pos_increases AND j1_pos_increases` |

The script finds every transition where each rule is true, groups consecutive matches into detected blocks, and then checks whether the first detected block for each phase appears in this expected order:

```text
pick -> lift -> place -> retract -> return_home
```

If all phases are detected in that order, the script reports that a pick-and-place motion was detected.

## How to Run

Run the script from inside this folder:

```bash
python check_pick_and_place.py
```

The script expects `full_motion_joint_states_modified.csv` to be in the same folder because the CSV path is defined as:

```python
CSV = Path("full_motion_joint_states_modified.csv")
```
